# מניין של אחד — התקנה על הטלפון

אפליקציית תפילה למתפלל ביחיד. אחרי ההתקנה היא עובדת **גם בלי אינטרנט**.

## שלב 1 — להעלות את התיקייה לאינטרנט (חינם, בלי הרשמה)

אנדרואיד מתקין אפליקציה רק מכתובת אינטרנט, לכן צריך להעלות את הקבצים פעם אחת:

1. היכנסו מהמחשב לאתר **app.netlify.com/drop**
2. גררו לשם את **התיקייה `app` כולה** (לא קובץ בודד)
3. תוך כמה שניות תקבלו כתובת כמו `https://xyz123.netlify.app`

*(אפשר גם GitHub Pages, Vercel, או כל אחסון אחר — העיקר שהכתובת מתחילה ב-`https`.)*

## שלב 2 — להתקין בטלפון

1. פתחו את הכתובת ב-**Chrome** בטלפון
2. יופיע פס "להתקין את האפליקציה על המסך הראשי?" — לחצו **התקן**
3. אם הפס לא הופיע: תפריט ⋮ בפינה ← **התקן אפליקציה** / *Add to Home screen*

האייקון יופיע במסך הבית ככל אפליקציה אחרת, והיא תיפתח במסך מלא בלי סרגלי הדפדפן.

## קיצורי דרך

לחיצה ארוכה על האייקון פותחת קיצורים ישירים ל**שחרית**, **מנחה** ו**ערבית**.

## עדכון גרסה

מעלים שוב את התיקייה לאותה כתובת. בפתיחה הבאה האפליקציה מושכת את הגרסה החדשה
(אם לא — לסגור ולפתוח שוב).

## הקבצים

| קובץ | תפקיד |
|------|-------|
| `index.html` | האפליקציה עצמה |
| `manifest.webmanifest` | שם, אייקון וצבעים בהתקנה |
| `sw.js` | שמירה במכשיר לעבודה אופליין |
| `icon-*.png` | אייקונים (רגיל ו-maskable לאנדרואיד) |

הערה הלכתית: התוכן בנוי על נוסח **תהלת ה'** (חב״ד). חלוקת הזמנים היא הערכה
לפי אורך הטקסט — לא הוראה הלכתית. בשבת וביום טוב האפליקציה נחה.
