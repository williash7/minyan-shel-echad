# מניין של אחד

עוזר תפילה למתפלל ביחיד — קצב אישי, לוח עברי, ונוסח התפילה המלא.
נוסח חב"ד, על פי סידור תהלת ה'.

## התקנה בטלפון

לפתוח את האתר בדפדפן, ואז בתפריט הדפדפן לבחור **"הוספה למסך הבית"**.
האפליקציה תיפתח במסך מלא עם אייקון, ותעבוד גם בלי חיבור לאינטרנט.

## איך נקבע הזמן של כל קטע

משך כל קטע נגזר ממספר המילים שבנוסח שלו בפועל. אם בחרת ארבעים דקות
לשחרית, האפליקציה מחלקת אותן בין 9,650 המילים שבתפילה — וכל קטע
מקבל בדיוק את חלקו. קטע שנאמר שלוש פעמים נספר שלוש פעמים.

## מבנה

- `index.html` — האפליקציה: מבנה התפילות, הלוח העברי וניהול הזמן
- `texts.js` — נוסח התפילה ומשקל הקטעים. נוצר אוטומטית; אין לערוך ידנית
- `content.js` — תוכן לימודי: ביאור המילים והסבר מתורת חסידות
- `sw.js` — שמירה מקומית לעבודה ללא אינטרנט
